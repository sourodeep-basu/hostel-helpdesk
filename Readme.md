Hostel Helpdesk is a web-based complaint management system that aims to make the process of making hostel-related maintenance complaints easy, organized and transparent. The complaints, which range from electrical and plumbing problems to damages to furniture, cleaning problems and security issues, are made along with the room number, urgency and affected area.

The software is able to prioritize the complaints according to rules set and classify them as Low, Medium, High or Critical

It provides an easy way of tracking the complaint through its defined stages; Submitted, Reviewed, In Progress and Resolved.

The admin interface provides the warden with a complaint overview by highlighting critical cases and enabling the modification of complaint details, as well as providing emergency contact information. Furthermore, the students are able to access the emergency contacts through the application to ensure they get any help they need immediately instead of waiting for actions to be taken on their complaints.

Overall, this system ensures accountability as well as a safe and secure hostel environment that is amiable to students’ needs.
